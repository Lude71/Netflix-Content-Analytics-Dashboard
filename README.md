# 🎬 Netflix Content Analytics Dashboard

## 📖 Project Overview

The Netflix Content Analytics Dashboard is a professional multi-page Power BI project designed to analyze Netflix's content library using interactive visualizations and business intelligence techniques.

The dashboard provides insights into content distribution, genre popularity, country production, ratings, directors, and release trends, helping users explore how Netflix's catalog has evolved over time.

---

# 📊 Dashboard Pages

## 1️⃣ Executive Content Overview

This page provides a high-level summary of Netflix's content library.

### Features
- Total Titles
- Total Movies
- Total TV Shows
- Total Countries
- Latest Release Year
- Content Ratings Overview
- Content Type Distribution
- Content Added by Year
- Top Content-Producing Countries
- Interactive Filters

---

## 2️⃣ Content Analysis

A detailed analysis of Netflix content.

### Features
- Top 10 Directors
- Top 10 Genres
- Country Distribution
- Release Year Trends

- Genre Analysis
- Country Analysis
- Interactive Slicers

Business intelligence and advanced analytics.
